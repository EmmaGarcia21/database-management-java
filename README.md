
# Database Management with Java

Implementation of database operations using Java and JDBC, focused on managing information about TV series and their seasons.

## Features
- Database connection management.
- SQL query execution.
- Insertion and retrieval of records.
- Updating database information.
- Querying series seasons.
- Handling SQL exceptions.
- Separation of database tasks and connection logic.

## Technologies
- Java
- JDBC
- SQL
- MySQL
- Object-Oriented Programming

## Academic Project
Developed as part of my Computer Science Engineering studies at UPM.
